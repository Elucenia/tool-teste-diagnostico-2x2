## إصدار الطريقة

2×2:الحساسية/النوعية/التنبؤ؛ويلسون 95% للنسب؛Simel 1991 فواصل لوغاريتمية LR؛ليس والد

## المعادلة الموثقة

الحساسية = TP / (TP + FN) · النوعية = TN / (TN + FP) · القيمة الإيجابية = TP / (TP + FP) · القيمة السلبية = TN / (TN + FN) · الدقة = (TP + TN) / المجموع.

LR+ = الحساسية / (1 − النوعية) · LR− = (1 − الحساسية) / النوعية.

فواصل 95%: ويلسون للنسب، ولوغاريتمي لنسب الترجيح (Simel 1991), الخطأ المعياري(ln LR+) = √(1/TP − 1/(TP+FN) + 1/FP − 1/(FP+TN)).

## الحدود والفئة السكانية

يتطلب الجدول تصنيفًا ثنائيًا للاختبار وللحالة المرجعية، مع أعداد متسقة للسكان أنفسهم. تعتمد القيمتان التنبؤيتان الإيجابية والسلبية على الانتشار، ولا تنتقلان تلقائيًا إلى سكان آخرين. قد يجعل المقام الصفري المقياس غير معرّف. فواصل Wilson للنسب والفواصل اللوغاريتمية لنسب الترجيح طريقتان مختلفتان؛ والأعداد الصفرية والعينات الصغيرة تتطلب تفسيرًا خاصًا. لا تثبت هذه التحليلات وحدها جودة المعيار المرجعي ولا تتحقق من صلاحية الاختبار.

## إعادة إجراء الاختبارات التقنية

شغّل node test.cjs في المجلد الجذري لهذا المستودع لتكرار الحالات الاصطناعية المسجلة. تُحفظ المدخلات والنتائج المتوقعة وحدود التفاوت الأصلية. لا تُعدّ الاختبارات التقنية تحققًا سريريًا.

```sh
node test.cjs
```

يحتوي tool.json على المصادر والإصدار ونطاق المراجعة. يحتفظ examples.json بالمدخلات والنتائج المتوقعة للحالات الاصطناعية؛ ويسجل results.json النتائج التي تم الحصول عليها.
